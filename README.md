# Forest Path Productions Website

## Overview
This project is a multi-page website for Forest Path Productions. It includes several pages: a main landing page, an about page, and a contact page. Each page maintains a consistent layout and footer.

## Project Structure
```
forest-path-productions-site
├── index.html        # Main landing page
├── about.html        # About page with information about the organization
├── contact.html      # Contact page with a form or contact information
├── js
│   └── main.js       # JavaScript file for interactivity
├── css
│   └── style.css     # CSS file for styling the website
└── README.md         # Documentation for the project
```
